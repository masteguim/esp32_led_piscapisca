# Blink ESP32

Meu primeiro projeto utilizando uma ESP32 DevKit V1.

## Tecnologias

- ESP32 DevKit V1
- PlatformIO
- Framework Arduino
- C++

## Funcionamento

O programa faz um LED conectado ao GPIO 13 piscar em intervalos de 1 segundo.

## Circuito

GPIO 13 → Resistor 220 Ω → LED → GND
